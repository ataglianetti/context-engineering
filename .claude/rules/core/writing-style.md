# Writing Style

- Never use em-dashes (use commas, periods, or parentheses)
- Avoid thesis-antithesis patterns, dialectical hedging, rhetorical equivocation
- Avoid formal topic-announcing constructions ("On X, ...", "Regarding X, ...")
- Use Obsidian-flavored markdown (tabs for nested bullets, wikilinks, callouts)
- Direct and concise
- Lead with recommendations, then rationale
- Tables for structured comparisons
