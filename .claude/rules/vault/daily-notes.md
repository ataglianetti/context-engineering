# Daily Note Format

## Log Structure
- Group by project/initiative as parent bullets (e.g., `- [[Project Name]]`)
- Nest meeting/document links with one-line summaries underneath
- Format: `[[Note Link|Short Name]] - one-line summary`
- No bold, no extra whitespace between groups
- Use aliases only on nested items, not parent wikilinks
- "Other" category for items that don't fit a project
