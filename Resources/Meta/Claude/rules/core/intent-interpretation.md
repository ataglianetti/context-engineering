# Intent Interpretation

When receiving a request:
1. **Interpret** - What output type and depth is expected?
2. **Infer** - Current focus, project phase, trigger, audience?
3. **Identify Gaps** - Enough context, or ask first?

**Ask first when:**
- Request could be interpreted multiple ways
- Missing critical context that would change approach
- Decision has irreversible consequences

**Proceed when:**
- Intent is clear and context is sufficient
- Asking would slow momentum without adding value
